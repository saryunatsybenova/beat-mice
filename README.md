# Бей мышей

Игра **«Бей мышей»** (Whack-a-Mole) для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

## 1. Как играть

- На экране **9 нор** в сетке **3 × 3**.
- Из случайных свободных нор **появляются мыши** и прячутся через **1 секунду** в фазе 1 и **0,7 секунды** в фазе 2.
- **Кликни по мыши** (мышью или касанием), пока она не спряталась, — получишь **1 очко**.
- **Пропущенная мышь** отнимает **1 жизнь**. В начале у тебя **5 жизней**.
- Партия длится максимум **90 секунд игрового времени**, без учёта паузы. Цель — набрать как можно больше очков.
- Партия заканчивается, когда **истекло время** или **закончились жизни**.
- На экране всегда видны **счёт**, **жизни** и **оставшееся время**.
- Перед началом показываются правила и кнопка **«Играть»**, после окончания — итоговый счёт и кнопка **«Заново»**.

### Фаза 2 (CR-002, новое условие CR-003)

При достижении **10 очков** (`score >= 10`) начинается фаза 2. Время больше не определяет переход. Под верхней панелью появляется надпись **«ФАЗА 2 · Мышки быстрее!»** с коротким миганием. Игровой цикл остаётся прежним, меняются два параметра:

| Параметр | Фаза 1 | Фаза 2 |
| --- | --- | --- |
| Интервал появления | 1,2 секунды | 0,8 секунды |
| Время показа мыши | 1 секунда | 0,7 секунды |

Переход не сбрасывает очки, жизни или мышей. Уже появившаяся мышь сохраняет прежний срок скрытия; правила фазы 2 применяются к новым мышам. После «Заново» снова включается фаза 1.

Фаза хранится в `GameState.gameStage` отдельно от состояния меню/игры/паузы (`phase`). `GameState.hit()` начисляет очки, проверяет `score >= BALANCE.phase2Score` и возвращает `true` только при первом переходе. `GameScene` получает этот результат, меняет интервал появления в `MouseField` и вызывает сигнал `GameUI.showPhase2()`.

На паузе очки не начисляются, поэтому переход невозможен. После продолжения сохраняются счёт и текущая фаза; пауза во второй фазе сохраняет её ускоренные параметры. Отсчёт 90 секунд партии по-прежнему исключает время паузы.

Проверка: при 9 очках должна оставаться «ФАЗА 1»; десятое попадание сразу включает «ФАЗА 2» и ускорение. На паузе при 9 очках нажатия не дают очков; после продолжения десятое попадание включает фазу 2. Повтори паузу во второй фазе пять раз, дождись конца и нажми «Заново»: должны вернуться 0 очков, «ФАЗА 1» и обычный темп. Само прохождение 60 секунд при счёте ниже 10 больше не включает фазу 2.

### Пауза (задание CR-001)

Во время партии **P** или **Esc** переключают состояния `playing` ↔ `paused`. P работает и при русской раскладке. Удержание клавиши не вызывает повторные переключения. На паузе видна надпись «ПАУЗА»; продолжить можно той же клавишей или кнопкой «Продолжить».

На паузе нельзя ловить мышей: очки и жизни не меняются, мыши не появляются и не прячутся, игровой отсчёт и текущие анимации остановлены. После продолжения сохраняются те же мыши и остатки времени, без пересоздания партии. В меню и на итоговом экране клавиши паузы ничего не делают.

Клавиши и приостановка Clock/Tween находятся в `GameScene.ts`: `handlePauseKey()`, `pauseGame()`, `resumeGame()`. Состояние и учёт времени — в `GameState.pause()` / `resume()`, экран паузы — в `GameUI.showPause()`. При продолжении `GameState` рассчитывает `deadline` заново от сохранённого `remainingMs`, поэтому время паузы не расходует партию.

Проверка по слайдам:

1. Нажми «Играть», затем P: должна появиться «ПАУЗА».
2. Подожди несколько секунд и нажимай на поле: время, счёт, жизни и мыши не должны изменяться.
3. Нажми Esc: игра должна продолжиться с прежнего состояния. Проверь также кнопку «Продолжить».
4. Повтори паузу и продолжение **пять раз подряд**. Проверь, что мыши не появляются чаще и одно попадание даёт только одно очко.
5. После продолжения дождись окончания по жизням или времени; нажми «Заново» и проверь 0 очков, 5 жизней, 90 секунд и работающую паузу.

## 4. Где лежит код игры

Схема текущей архитектуры и связи компонентов: [ARCHITECTURE.md](ARCHITECTURE.md).

Код разделён по обязанностям. Новую механику удобно начинать искать в правилах, её визуальную реакцию — в интерфейсе.

| Файл в `src/game/` | За что отвечает |
| --- | --- |
| [`settings.ts`](src/game/settings.ts) | Все параметры баланса в объекте `BALANCE`: время, жизни, очки, порог и параметры обеих фаз, сетка и область попадания |
| [`GameState.ts`](src/game/GameState.ts) | Состояние партии и правила: очки, жизни, фаза, время, пауза и сброс; без зависимости от Phaser |
| [`GameScene.ts`](src/game/GameScene.ts) | Связь компонентов, ввод мышью/касанием и P/Esc, запуск, пауза Clock/Tween, завершение и очистка при перезапуске |
| [`MouseField.ts`](src/game/MouseField.ts) | Рисунок сада и нор, поиск мыши под указателем, случайное появление, скрытие, анимации мышей и их таймеры |
| [`ui/GameUI.ts`](src/game/ui/GameUI.ts) | Счёт, сердечки, время, индикатор фазы, «+1», реакция на пропуск, меню, пауза и итоговый экран |
| [`ui/widgets.ts`](src/game/ui/widgets.ts) | Общие панели, текст и кнопки с наведением/нажатием |
| [`visuals.ts`](src/game/visuals.ts) | Рисунок мышки, общий для поля и меню |
| [`theme.ts`](src/game/theme.ts) | Палитра `COLORS`, длительности эффектов `ANIMATION`, размеры графики |
| [`config.ts`](src/game/config.ts) | Создание Phaser.Game, сцена и масштабирование canvas |

**Как проходит попадание:** `GameScene.handlePointerDown()` → `MouseField.findMouse()` → `GameState.hit()`. Затем сцена обновляет `GameUI`, убирает мышь через `MouseField.clearMouse()` и при необходимости меняет параметры появления. Интерфейс не начисляет очки, а поле не решает, сколько отнять жизней.

**Три ручки настройки из задания** находятся рядом в [`settings.ts`](src/game/settings.ts):

```ts
export const BALANCE = {
  durationMs: 90_000,  // продолжительность партии
  startLives: 5,      // стартовые жизни
  phase2Score: 10,    // счёт для перехода в фазу 2
  // остальные параметры — в том же объекте
};
```

Полный список параметров:

| Поле `BALANCE` | Значение | Что меняет |
| --- | --- | --- |
| `durationMs` | `90_000` | длительность партии без пауз, мс |
| `startLives` | `5` | начальное число жизней |
| `hitPoints` / `missLives` | `1` / `1` | награда за попадание / цена пропуска |
| `phase2Score` | `10` | порог второй фазы |
| `phases[1].spawnIntervalMs` | `1_200` | интервал появления в фазе 1, мс |
| `phases[1].mouseVisibleMs` | `1_000` | время показа в фазе 1, мс |
| `phases[2].spawnIntervalMs` | `800` | интервал появления в фазе 2, мс |
| `phases[2].mouseVisibleMs` | `700` | время показа в фазе 2, мс |
| `gridCols` / `gridRows` | `3` / `3` | число нор; при увеличении сетки потребуется подогнать компоновку |
| `mouseHitRadius` | `58` | радиус попадания в координатах макета |

Все времена указаны в миллисекундах. После изменения настроек начни новую партию. Цвета и длительности эффектов меняются в `theme.ts`; размеры макетов — в `GameScene.layout()`, расположение нор — в `MouseField.createHoles()`, расположение интерфейса — в `GameUI`.

Графика, надписи и поведение сохранены. Картинки, внешние шрифты и новые библиотеки не добавлены.

## 5. Проверка production build

Проверка типов отдельно: `npm run typecheck`.

После `npm run dev` или `npm run preview` проверь:

1. До нажатия «Играть» видны правила; мыши не появляются.
2. После старта — 9 нор, счёт 0, 5 жизней и 90 секунд.
3. Попадание мышью или касанием даёт одно очко. Повторное нажатие в пустую нору ничего не меняет.
4. Мышь исчезает через секунду; пропуск отнимает одну жизнь. При пяти пропусках появляется итоговый счёт.
5. Нажми «Заново»: новая партия начинается сразу со счётом 0, пятью жизнями и новым отсчётом 90 секунд. Повтори несколько раз.
6. Лови мышей до окончания времени: при нуле секунд игра заканчивается, дальнейшие нажатия не дают очков. Можно временно уменьшить `BALANCE.durationMs` в `settings.ts` для быстрой проверки, затем вернуть `90_000`.
7. Сверни вкладку более чем на 90 секунд: при возвращении активная партия должна завершиться. Если включена пауза, состояние должно оставаться замороженным. Время считается по реальным часам браузера; скрытая вкладка не продлевает партию.
8. Проверь касания и небольшой экран: поле должно помещаться, касание canvas не должно прокручивать страницу. Поверни телефон во время партии: счёт, жизни и таймер не должны сбрасываться. Проверь состояния кнопок и всплывающие подсказки при попадании/пропуске.

Таймер исчезновения принадлежит конкретной мыши и отменяется при попадании. При завершении партии удаляются игровые таймеры; перезапуск также очищает обработчик ввода.

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 6. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` или `master` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.
